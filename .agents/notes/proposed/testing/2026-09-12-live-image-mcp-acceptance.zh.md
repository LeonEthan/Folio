## 摘要

现有安装包的生图与编辑证据主要来自模拟供应商，不能证明真实图像服务能够用于多图平面设计。用户明确要求真实测试包含图像生成与编辑，并提供 AruHub image2 的测试连接。将真实 Folio MCP 调用、图片进入 PPTD/Bento、多图保存导出及人工视觉检查列为必做待办；既有模拟测试继续验证确定性协议和错误路径。本文只记录测试任务与非机密配置，尚未执行请求，不宣称供应商可用或图像质量通过。

## 必做 TODO

- [ ] **真实安装包连接与 MCP 入口。** 固定实际安装包/产品源、操作系统及用户选择的 Agent/runtime/ACP，使用已有设置保存上述连接。记录真实暴露的 image generate/edit 工具和调用路径，确认 model 原样发送、没有产品默认值或模拟响应替代。机密配置缺失时明确记录阻塞，不回退假数据并标通过。
- [ ] **真实 generate。** 通过 Folio MCP 生成至少 3 张不同的测试素材，例如产品主体、场景背景和装饰插图；保存返回的真实图片字节，核对 MIME、可解码性、尺寸及素材路径。实际打开图片，不能只看 HTTP 200、返回 URL 或模型的成功描述。该最小样本供后续多图画稿复用，避免每个场景重复生成同一素材。
- [ ] **真实 edit。** 使用上述一张真实输出作为输入，通过 Folio MCP 至少完成一次有明确可视变化的编辑，例如保持产品形状和构图、把蓝色主体改成红色。核对传入的原图与请求关联、返回的新素材及原图保留，人工比较是否完成目标且主体可辨；不能以另一张无输入的 generate 冒充 edit。多参考图和 mask 按拟宣称支持的实际组合补测；不支持时记录限制，不静默改协议或放宽结论。
- [ ] **生成/编辑 → Agent 读图 → PPTD/Bento。** 使用一个实际支持 Folio MCP 的已配置 Agent 完成调用与真实图片读取，把生成素材用于可编辑画稿；再从选中图片执行编辑并替换目标。确认图片工具本身不提前提交画稿，最终图片引用与确切字节一致，无关元素和旧素材保持正确。Provider 接通、Agent 真正获得图片输入、视觉质量分别记录。其他 Agent 的发现/传输/读图仍归五 Agent 矩阵，不能凭一个 Agent 通过替它们盖章。
- [ ] **真实图片负载的保存、恢复与导出。** 至少包含一份 12 个图片元素的多图长图或信息图，以及一份使用真实主体/背景图片的海报。记录独立素材数、原始尺寸及总字节数，至少使用上述 3 张不同真实生成图和编辑输出；复用相同图片时如实记录，不以微型占位图充数。验证裁切、缩放、替换、撤销/重做、自动保存、退出重开、PPTD 往返和 PNG/JPEG 导出，无丢图、错图或失效素材路径。测量加载、编辑、保存、导出与峰值内存，供人工判断目标机器可接受性；不预设未经验证的性能通过阈值。
- [ ] **失败与视觉结论归档。** 真实服务出现失败、超时、权限或不支持参数时保留错误事实和已有素材/画稿，不用重复付费请求掩盖失败。故意制造的 HTTP/超时/损坏图/取消等负例优先复用现有模拟设施，不为异常覆盖反复调用真实服务。汇总每次真实调用数量、耗时、响应类型、输出尺寸/摘要及可观测用量/费用，未知费用标未知。人工分别评定生图可用性、编辑目标达成和多图版式/交互体验，不能由自动检查代填。

测试用例的固定输入/断言只约束验收，不写入产品 skill 来强制 Agent 按固定创作步骤工作。图像生成具有不确定性，真实测试不按图片逐像素相等判断成功；技术完整性和视觉判断分别报告。
