# Folio 平面设计工作台

Status: draft
Translation: pending

## 使用场景

用户发起设计会话，输入需求并添加参考图，使用本机 Agent 生成可编辑的平面设计；随后通过选中元素对话或手工修改，保存、重开并导出图片。用户通过会话历史查找历史产出，不管理独立作品目录。正常创作不要求 Git 仓库、分支、终端命令或代码审查知识。

本草案根据已获方向性认可的改造清单制定，具体行为仍待复核。已实现 P0 固定样稿及 P1 手工编辑闭环；阶段证据见文末，不表示整个产品已获视觉或发布验收。

## 产品范围

- 本地单人桌面工作台；每个作品一个静态画布，项目可组织多个作品。
- 覆盖海报、封面、社交配图、横幅、信息图、长图和通用电商图片；场景知识放在技能和参考材料中。
- 保留 Folio 现有桌面架构、UI 设计语言、Agent 接入及本地会话能力；迁入 Bento 的文档、编辑和渲染能力。
- 首期交付 PNG/JPEG。多画板、演示文稿、视频、模板市场、云协作及其他专业格式不属于本草案。

首页保留原有顶部与对话输入结构，尺寸选择与项目目录处于同一行最右侧，右边缘对齐输入框，不单独堆叠一行，不提供独立的新建设计按钮或名称输入。尺寸默认 Auto，不要求预填宽高；切换自定义后才显示并校验宽高。输入内容并按回车时复用现有 Session 提交及自动命名流程，同时初始化空白单画布作品；Auto 在 P1 使用默认初始画布，后续可在编辑器调整，尚不承诺 Agent 根据内容自动计算尺寸。创建失败保留输入草稿。提交沿用现有 Agent 配置要求，作品打开后的手工编辑不依赖 Agent 执行。

## 职责和持久化

设计产出保存在会话使用的本地 workspace 中，只维护最新状态。会话历史记录交流过程，不提供各回合画稿快照或历史版本打开能力。设计会话记录讨论和执行过程，首期默认一个作品对应一个主会话。会话归档和删除沿用原项目语义，不新增删除普通 workspace 文件的行为；删除会话记录不等于删除本地设计文件。既有 Git worktree 清理规则不因此改变。

现有 CLI 后台继续负责 Agent 生命周期、权限回应、会话与回合。设计服务负责文档校验、素材登记、候选协调及当前画稿保存；Electron 负责桌面资源、可信编辑器桥接、渲染进程与原生文件交互。设计服务不另建一套 Agent 调度和聊天存储。

BentoDoc 是当前画稿唯一可编辑文档；PPTD 是创作输入，预览图和导出图是派生产物。现有 Loro/Flock 保存会话及作品关联，本地 workspace 保存当前画稿与素材，不把两者变成可分别修改的重复画稿。

会话及产物身份是关联依据；并发保存的基线标识只用于检测状态变化，不表示保存历史版本。会话元数据的写入或通知失败不得撤销已持久化的作品；重开时能根据已持久化的关联恢复，具体提交与修复机制在技术切片中确定。用户不应因通知迟到而重复生成同一作品。

## 编辑和 Agent 回合

P1 支持宽高各 1–4096 像素的单画布，手工调整画布尺寸时保持元素位置和大小；若调整后有元素超出画布，拒绝该调整并说明阻塞元素，不自动缩放或裁切。

1. 提交设计输入前确认当前编辑已保存，并固定作品、当前稿基线、选区、参考材料与本次设计技能；保存失败时保留用户输入并说明原因。
2. 模型、权限和工具能力由当前 Agent 的真实能力决定；不伪造支持状态，不静默切换 Agent，也不代替用户回答权限请求。
3. Agent 自然完成后收集并校验候选；文件出现不代表完成，Agent 回合成功也不等于有效画稿已经提交。
4. 人工编辑和 Agent 候选通过同一设计服务提交。写入检查预期当前状态；不冲突的修改可协调，无法证明安全的修改保留为独立候选，不能覆盖当前稿。
5. 重新生成的候选提供比较、采用和拒绝。采用时再次核对当前状态，重复请求不能重复应用；拒绝不改变当前画稿。
6. 失败、取消、缺失产物、校验失败及候选待处理分别呈现。重启不自动重新发起模型调用；继续动作沿用现有恢复合同。
7. 元素引用携带作品、当前稿基线及稳定元素 ID；选区失效时明确提示，不猜测另一元素作为目标。

## 保存、恢复和导出

- 自动保存、切换作品、关闭标签和退出应用共享保存确认语义。失败必须可见，不能声称已保存；运行时与画稿保存采用各自真实状态。
- 切换作品、关闭标签或退出时保存失败，阻止该动作并保留未保存修改；用户可重试或明确放弃修改，不能静默丢稿。
- P1 并发保存发现基线过期时拒绝写入，保留本编辑器的未保存修改；用户可另存为独立作品，或明确放弃修改并重新加载已保存当前稿。不自动覆盖或合并；后续 Agent 候选协调另按其阶段合同实施。
- 冲突另存创建新作品及空白主设计会话，将画稿与必需素材复制到新会话的 workspace，原作品保持不变；不复制交流记录或撤销历史。另存失败时保留未保存修改，并继续阻止切换、关闭或退出，直至保存成功或用户明确放弃。
- 意外崩溃或断电后恢复最后成功保存的画稿及素材；仍处于待保存或保存中状态的修改可能丢失。P1 不承诺崩溃恢复未确认保存的草稿，正常离开动作仍执行保存保护。
- 当前不提供画稿历史版本、版本列表或历史恢复，也不迁入不可变修订库。未来若提供历史还原，再基于 Git 单独设计；编辑器当前运行中的撤销/重做不构成持久化历史承诺。
- 作品标签仍打开时，切换作品或视图保留该编辑器的撤销/重做状态；关闭标签或重启后不保留撤销历史，已保存当前画稿不受影响。
- 正式导出基于已保存的当前画稿，使用固定编辑器渲染路径、字体和素材。导出前处理当前未保存修改，不能悄悄导出旧稿。
- PNG 保留透明度；JPEG 透明区域填白。像素尺寸按画布实际尺寸输出；缩放仅影响界面显示。
- 无效文档、缺失素材、字体或渲染失败须报错，不用占位图或窗口截图冒充成功导出。
- 首期不提供作品目录管理或相邻项目作品目录导入功能；旧程序数据保持原状。

## 工作台与边界

保留侧栏、标签页和对话输入结构；默认对话与较大画布并排，提供专注画布模式。素材、图层和属性按需展开，窄窗口切换视图时保留编辑状态。去掉幻灯片、演示及其他不支持的编辑器入口。

Git/PR/CI 等开发功能退出设计主流程，并停止其不再需要的后台工作。共享基础设施只在确认没有消费者后删除。新应用身份与数据目录须与现有 Lody 和相邻程序隔离。

遵循 [平台边界](../packages/platform/AGENTS.md) 和 [共享协议合同](../packages/shared/AGENTS.md)：不引入认证产品云请求或遥测。用户选择的 Agent 及图像服务仍可能访问外部模型，本地优先不等于离线生成；凭据不进入画稿、Role 或日志。没有 Agent 或图像服务时，已有作品仍可编辑、保存和导出。

## 待定项

- 首个真实设计验收使用当前可用接入，不绑定特定 Agent。Pi 与其他 coding agent 一样属于用户侧选择，不是 Folio 的前置依赖；具体能力以各接入的验证结果为准。
- P0 以 macOS 实机开发版及安装包通过为阶段门槛；Windows/Linux 同期执行构建与资源探针。首发操作系统及架构矩阵仍待实机证据确定。
- workspace 内画稿与素材的具体文件布局在 P0 核对；复用现有会话目录，不新增作品目录管理。
